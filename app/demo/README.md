# 哲学小猫 · 演示 HTML（故事、网页版、桌宠与技术展示）

纯静态 HTML / CSS / JavaScript。前半段是小猫的故事，后半段复用真实网页版界面，播放事先通过现有聊天引擎生成的圆桌内容。观看演示不发起模型请求。
直接打开 `index.html` 即可；也可在仓库根运行：

```sh
python3 -m http.server 8791 --bind 127.0.0.1 --directory app/demo
```

完整演示从 `http://127.0.0.1:8791/#cover` 开始，依次为封面 → 困惑 → 门后的世界 → 网页版 → 桌宠 → 哲学家的知识与对话技术。

## 演示

- 封面：左侧完整标语，右侧电脑桌面；左下角小猫每 3 秒切换一组动作，精灵帧约 6 fps。
- 纸片弹语使用库内老子 `dao-33-self-knowing` 条目及原有气泡轮廓。
- 点击“跟着小猫，往里走”或按右方向键，小猫沿平缓路线跑出屏幕，约 2 秒内逐渐放大来到第二页中央；朝向跟随移动方向。
- 第二页标题固定，9 句困惑分批浮现，停留约 1.5 秒后向小猫聚拢、缩小、消失；完整循环约 23.5 秒。
- 第二页使用新的摘帽挠头动画，保留摘帽、放帽、反复挠头与烦恼停顿的完整 5.88 秒循环；不叠加旧的晃动或问号。
- 第二页点击“继续往前走”，直接开始小猫向门前跑去、门缓缓打开的动画，第二页困惑同时淡出；随后标题“这些问题，也曾有人用一生追问。”浮现，总计约 2.9 秒。独立问题文字、问题转化及中间停顿均已删除，也没有小猫转身邀约或新增弹语。宽屏的门比上一版明显放大。
- 点击“跟着小猫，去见见他们”，视线在约 2.6 秒内向门后的世界推进，门内区域覆盖整个视口后淡出，衔接网页版展示。
- 深度聊展示六位已接入哲学家的真实初始页面，每位完整停留 2 秒，切换时用 0.5 秒交叉渐变；六位开场页共约 14.5 秒，保留现有肖像、背景、姓名和原始开场语，不发送用户消息。依次是马可·奥勒留、庄子、老子、孔子、尼采、加缪。
- 圆桌派展示真实提示词“你们怎么看待亲密关系？”，随后重现默认马可、庄子、尼采的两轮共六段发言。正文逐段生成，视图跟随最新发言；最后一段生成完毕即停住，删除生成结束后的自动上下浏览。完整保留所有发言。原始文本中的格式标记按正式网页相同规则显示。
- 网页版底部提供“返回上一页”“重新播放”和“继续看”三个浮动按钮，整条播放器、进度条、模式标签、页码及暂停按钮均已移除。“返回上一页”回到已打开的门前，播放中、暂停或加载中都可以返回。“继续看”在加载中、哲学家渐变中、圆桌生成中或生成结束后都可直接进入桌宠环节。“重新播放”从第一页开场语开始播放；减少动态效果偏好下保持静止。网页版自身顶部导航保留，空格仍可暂停或继续。圆桌标题旁的“选择入场者”/“新开圆桌”保留展示，但不可点击或通过键盘触发；隐藏菜单内的“新开圆桌”也禁用。
- 桌宠页标题为“不必专程寻找，哲学也会来到你身边。”，副文案为“安静陪伴在桌面一角。偶尔一句哲人的话，把思考带回日常。”虚拟电脑右下角的小猫先静止，随后切换阅读动作并弹出手绘气泡；虚拟鼠标约在 4.8 秒点击“看出处”，9 秒点击“说人话”，约 9.65 秒显示通俗释义并切换说话动作，14.5 秒后静止保留释义。
- 桌宠气泡复用正式客户端的轮廓、按钮名称和精灵动作。“看出处”显示原文与篇章；“说人话”按照正式客户端的 shortenPlain 规则截取现有概念卡，不调用模型。按钮也可手动点击并暂停在对应画面，桌宠页提供“返回上一页”“重新播放”和“继续看”；返回可重新查看网页版演示，任意时刻点击继续，都进入技术展示页。
- 第六页标题为“一句回答背后，是一套有来处的思想。”；在约 4.4 秒内依次展示原著语料、思想蒸馏、哲学家知识库、专属对话引擎，随后保留完整画面供阅读。下方展示从现有知识包计算的规模，点击“沿着刚才那句老子，看看真实的蒸馏材料”，可以展开原文、通俗释义、思维框架、人格与困境映射，说明这些内容如何编译进入 System Prompt。展开时完成并暂停动画，重播关闭材料、回到顶部并重新播放。
- 左方向键返回上一页，右方向键推进当前页（网页版跳到桌宠，桌宠跳到技术展示），Esc / 标志返回封面；每页可重播。第三页重播从跑向门前开始，返回第二页重新播放困惑与挠头循环。
- 减少动态效果偏好下默认暂停，第二页静态显示三句主要困惑和挠头姿势；第三页直接显示开门后的标题，点击结尾按钮直接进入网页版，自动切换与滚动保持暂停；桌宠页直接展示静止的通俗释义，不播放鼠标和点击动画；技术展示直接呈现完整静态内容。
- `#questions`、`#world`、`#showcase`、`#companion`、`#craft` 可直接打开相应部分；新素材独立预加载、解码，失败时保留当前页并允许原按钮重试。小猫、文字、开门、镜头推进、网页版切换、对话生成、桌宠鼠标和技术展示共用父页面的时钟，暂停和后台切换同步冻结。

## 真实圆桌与网页版快照

- `assets/showcase/roundtable.json`：2026-09-10 通过本机 `/roundtable/sessions` 接口实际生成，模型 GLM-5.2；默认三位哲学家各发言两次，共 6 段。保存完整 `speaker_done` 原文、SSE 事件及录制时间；没有代写或拼接回复。
- 生成使用新建的 `demo-capture-*` 身份，不读取用户已有会话。录制完成后删除本次临时圆桌会话。模型请求发生在制作演示时，播放时完全离线。
- `showcase/`：从当前 `app/web/` 复制 HTML、样式、肖像和背景；替换联网控制脚本为演示驱动。`source.json` 记录源文件摘要，`data.js` 包含六位哲学家显示配置和真实圆桌正文。iframe 隔离正式网页样式；父子窗口校验消息来源，使用统一播放进度。
- `capture_roundtable.py` 可重新真实生成一桌（会调用模型）；`prepare_showcase.cjs` 只刷新页面快照，不调用模型。更新正式网页或实录后再执行准备脚本。

```sh
# 仅需要重新录制时执行，要求现有 8848 服务已启动。
python3 app/demo/capture_roundtable.py
node app/demo/prepare_showcase.cjs
```

## 桌宠数据

- `desktop-data.js` 保存库内老子 `dao-24-tiptoe` 弹语、出处、完整 plain 层及按正式客户端规则截取的释义；记录概念卡路径和 SHA-256，回归检查与原知识卡比对。
- `desktop-demo.js` 提供可逐帧复现的桌宠时间线及渲染器，鼠标移动、点击波纹、来源展开和角色换帧共用现有主时钟。桌宠所需壁纸和原始精灵表独立解码，网页版加载失败也能跳过；失败时可重播重试。

## 哲学知识与技术展示

- `prepare_craft.cjs` 只读现有六位哲学家的语料、概念卡、思维框架、人格、困境映射、范例和编译产物，生成 `craft-data.js`。当前快照包含 6 位哲学家、1,265 条语料、33 张思维框架、61 张概念卡和 9 份对话范例；页面展示前四项。语料计数按各知识包内唯一 ID 去重，涵盖原典、译本和选段，不代表完整原著册数。
- 展示的“蒸馏”指原著与思想的内容整理、提炼和结构化。实际编译器把知识材料、人格和对话规则组装成专属 System Prompt，服务端再结合对话上下文调用语言模型；没有将此包装成模型权重训练或实时向量检索。
- 老子例子复用上一页 `dao-24-tiptoe`。准备脚本检查原句与语料匹配，并确认原句、概念与框架出现在当前老子编译提示词中。`craft-data.js` 记录材料路径与 SHA-256，回归检查与仓库实际文件比对。更新知识包后执行 `node app/demo/prepare_craft.cjs` 刷新快照；若同时修改桌宠引用的卡片，也需刷新 `desktop-data.js`。
- `craft-demo.js` 使用确定性时间线接入父页面时钟，暂停、后台恢复、重播、减少动态效果与其他页面同步。底部仅有“重新播放”和“返回上一页”两个按钮；窄屏改为两列流程卡，材料纵向排列并可滚动阅读。

## 校验

```sh
node --test app/demo/test_motion.cjs
node app/demo/build.cjs
```

`build.cjs` 检查脚本语法、故事与网页版的本地资源引用，把独立预览产物放入 `app/demo/dist/`。入口中的资源版本参数用于更新已有浏览器缓存，不影响直接打开 HTML。回归检查还校验六位开场语、六段真实发言与原始素材一致，以及每位开场页完整停留 2 秒，背景、肖像与对话框同步交叉渐变且共享暂停时钟、生成结束立即完成并暂停。

浏览器验收通过本机 HTTP 预览完成，覆盖穿门、开场语、任意时刻跳过、中间环节的返回按钮、桌宠出处展开、技术页流程与材料展开、六页导航和手机端布局。当前浏览器工具策略禁止访问 `file://`，因此未自动验证直接双击 HTML 的打开方式。
