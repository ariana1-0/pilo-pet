# philo-pet 测试版首次打开

这是随安装包一起发给测试者的安装说明，不是客户端里的注册或引导页面。

## macOS

1. 打开 DMG，把 `philo-pet` 拖进“应用程序”。
2. 第一次打开时，系统可能提示无法验证开发者。先关闭提示，再打开“系统设置 → 隐私与安全性”，在安全区域找到 philo-pet，点击“仍要打开”。
3. 桌宠启动后会出现在桌面右侧，顶部菜单栏也会出现入口。

## Windows

1. 运行 `Setup.exe`。
2. 如果 SmartScreen 提示未知发布者，点击“更多信息 → 仍要运行”。
3. 桌宠启动后会出现在桌面右侧，系统托盘里也会出现入口。

## 使用提示

- 点击小猫打开或关闭弹语；点击弹语纸片可换一句。
- 按住小猫约四分之一秒后可以拖动位置。
- 从菜单栏或系统托盘可以调整整体大小、换动作或退出。
- 第一次使用或服务休眠后，加载弹语和对话可能需要约一分钟。
