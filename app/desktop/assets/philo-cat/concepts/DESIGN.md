# Philo Cat 桌宠形象设计 · v1

## 角色方向

一只喜欢看书的白色小猫，松弛、呆萌，有好奇心，也会犯困。它像陪用户一起读书、一起想事情的朋友，神情亲近，动作轻巧。

使用有轻微抖动和粗细变化的粗黑手绘线条，搭配大块白色猫身与少量黑色细节。保持轮廓简洁，让眼镜、猫耳、帽子和书在缩小观看时仍然容易辨认。

固定识别元素为圆眼镜、戴歪的黑色学士帽和一本厚书。各姿态沿用同一套体型、五官位置、眼镜与帽子比例；允许眼镜滑落、帽子倾斜和帽穗摆动，强化小猫的生活感。蓝色作为概念展示底色，衬托黑白角色；姿态变化主要靠肢体和表情表达。

## 十二种状态与姿态

| 状态 | 姿态与表情 |
| --- | --- |
| 抱书待机 | 两爪抱住合上的书，微微歪头，尾巴绕在身旁。 |
| 专心阅读 | 摊开厚书，只露出眼镜、猫耳和帽子，身体缩成一团。 |
| 小心翻页 | 一爪压书、一爪掀起书页，眼睛追着页面移动。 |
| 推镜思考 | 一爪推眼镜，另一爪扶书，视线向上飘。 |
| 抬头倾听 | 暂停阅读，用爪子夹住书页，侧头看向用户。 |
| 分享发现 | 把书轻轻转向用户，一爪指着书页，露出小小笑容。 |
| 突然想通 | 身体坐直，举起一只爪，眼睛睁圆、帽穗轻扬。 |
| 有点困惑 | 脑袋歪得更明显，眼镜轻斜，尾巴弯成问号状。 |
| 困困哈欠 | 一爪揉眼，嘴巴张成小圆，书滑到肚子前。 |
| 趴书睡觉 | 趴在摊开的书上，眼镜滑到鼻尖，帽子歪在一侧。 |
| 伸个懒腰 | 前爪伸远、屁股微翘，尾巴舒展，书留在爪边。 |
| 开心招手 | 一爪抱书、一爪挥动，眼睛弯起来，身体轻轻侧倾。 |

## 本轮交付

- `master-v1.png`：1254 × 1254 px、RGB PNG，方形角色主形象；抱书坐姿。
- `poses-v1.png`：1448 × 1086 px、RGB PNG，四列三行的十二态姿态总览，按从左至右、从上至下的顺序对应上表。

两张图均为静态概念设计，使用蓝色展示底。本轮不接入桌宠客户端，不将概念图视为已拆分的透明素材或可直接播放的动画。提示词另存于 `PROMPTS.md`。

图片使用内置 imagegen 生成，保持原始输出尺寸与像素内容；本目录包含项目内的完整 PNG 副本，不依赖生成工具缓存目录。

## 视觉验收标准

- 白猫、粗黑手绘线条与蓝色展示底一致；眼镜、歪学士帽、厚书形成清楚的角色识别。
- 十二种状态均有对应姿态，动作和表情可区分，不依赖文字标签才能看懂。
- 跨姿态保持同一只猫的体型与五官比例；爪子、书页、眼镜和帽子结构自然，无多余肢体或意外缺失。
- 构图完整，猫耳、尾巴、帽穗和书未被裁切；缩小观看仍能辨认主要轮廓与关键表情。
